1. Открыть папку hw\_llm.

2\. Создать там текстовый файл.

3\. Назвать его README.md (важно, чтобы расширение было именно .md, а не .txt).

4\. Открыть его Блокнотом и вставить следующий текст:



**# Генератор тестовых сценариев с использованием LLM**



**Этот проект представляет собой Python-скрипт для генерации тестовой документации (тест-кейсов) с помощью локальной нейросети через Ollama.**



**## Требования и установка**



**1. Установите \[Ollama](https://ollama.com/) для вашей операционной системы.**

**2. Запустите Ollama и скачайте необходимую модель (в скрипте используется `qwen3.5:4b`). Выполните в терминале:**

&#x20;  **```bash**

&#x20;  **ollama run qwen3.5:4b**



5\. Установите библиотеку requests для Python:

pip install requests

6\. Скрипт принимает один аргумент командной строки — количество генерируемых сценариев (--count).

Запустите скрипт из папки с проектом:

python generate\_tests.py --count 5



(где 5 — это нужное вам количество тест-кейсов)



7\. После выполнения скрипта в папке появится файл test\_scenarios.md с готовыми сценариями в формате Markdown.



\*\*Что делать дальше:\*\*

После того как создадите и сохраните этот файл, у вас в папке `hw\_llm` будет ровно три файла:

1\. `generate\_tests.py`

2\. `test\_scenarios.md`

3\. `README.md`



Именно эти три файла вы и будете загружать в свой новый публичный репозиторий на GitHub!
